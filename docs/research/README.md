# Индекс исследования внешних репозиториев

Изучены внешние репозитории (≥150) по шести направлениям. Подробности в файлах:

- `next-shadcn-design.md` — Next.js 16 / App Router / shadcn-ui / Tailwind / Vercel: ролевые layout'ы, навигация, bento-дашборды, тёмная тема, шрифты, деплой.
- `design-systems.md` — дизайн-системы и токены: семантические цвета, hairline-бордеры, доступность, калиграфика.
- `lms-edtech.md` — open-source LMS/EdTech: ролевые дашборды, страницы курсов, lesson player, прогресс, сертификаты, квизы.
- `web-security-next.md` — безопасность Next.js/Auth: RBAC, CSP-nonce, сессии, валидация, rate limiting, зависимости.
- `ai-agent-orchestration.md` — оркестрация ИИ-агентов: скиллы, субагенты, MCP, паттерны оркестрации для качества текста и security-гейтов.
- `text-quality-humanize.md` — качество/очеловечивание текста: humanizer-ru, детекторы, eval, смежные техники.

Каждый файл содержит конкретные применимые паттерны со ссылками на репозитории.
