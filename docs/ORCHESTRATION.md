# Оркестрация качества и безопасности

Правила постоянного (always-on) применения двух скиллов к проекту
«AI Strategic Academy». Этот файл подключён в `opencode.json` → `instructions`.

## 1. Русский текст — всегда через humanizer-ru

- Любой русскоязычный текст **для людей** (UI-копирайт, описания, сообщения,
  документация, письма, посты, развёрнутые ответы пользователю) перед выдачей или
  коммитом прогоняется через скилл `humanizer-ru`:
  - убирать HARD BANS (см. каталог скилла) в первую очередь;
  - контрастное вычитание: заменять самые предсказуемые слова на менее вероятные,
    но характерные;
  - держать burstiness (чередование длины/структуры предложений);
  - сохранять фактическую точность (Факт-замок: не выдумывать цифры/имена).
- Полный источник скилла всегда доступен как reference `humanizer-ru`
  (`tools/humanizer-ru` — клон репозитория, скачан локально) и как загруженный
  скилл `humanizer-ru`.
- Для глубокой правки русского текста можно делегировать субагенту `text-humanizer`.
- **НЕ применять** к: коду, идентификаторам, commit-сообщениям, коротким техническим
  ответам в терминале.

## 2. Безопасность — всегда сверяться с OWASP Top 10:2025

- При написании и ревью **любого** кода загружай скилл `owasp-top10-2025` и проверяй
  изменения по чеклисту. Локальная копия чеклиста — `docs/owasp-top10-2025.md`
  (reference `owasp-top10`).
- Минимальный объём проверки — категории, затронутые изменением; при ревью или словах
  «безопасность/уязвимость» — все десять (A01–A10).
- Для целенаправленного security-ревью можно делегировать субагенту `security-guard`.
- Найденные проблемы нельзя оставлять молча: либо исправь, либо явно перечисли в ответе
  с указанием категории (A01–A10) и способа исправления.

## 3. Субагенты (opencode)

- `text-humanizer` — очеловечивание русского текста по скиллу humanizer-ru.
- `security-guard` — ревью изменений по OWASP Top 10:2025.

Запускать субагентов через Task-инструмент, когда объём текста/кода велик или нужен
независимый проход (например, перед коммитом большого изменения).
